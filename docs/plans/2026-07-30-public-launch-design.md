# Make It Visible · 公开发布设计

## 目标

把现有的 Vue 官网与最新纯前端愿景板编辑器合并成一个可独立部署的公开产品。首发版优先保证任何人打开即可创作、照片不离开浏览器、无需账号与服务器维护。

## 方案

- `frontend/` 是唯一公开入口，提供首页、功能、案例、反馈与隐私说明。
- `frontend/public/editor/` 内嵌最新编辑器，所有主 CTA 直接进入编辑器。
- 官网内容改为本地静态数据，不再要求 Django API 在线。
- Django 代码暂时保留，供未来出现真实的后台管理、账号或云端存储需求时再生产化。
- 案例使用一张 3×2 愿景板视觉图，通过 CSS 安全裁切成六张独立案例卡，并复用为社交分享素材。

## 数据流

用户访问官网 → 浏览案例/功能 → 进入 `/editor/index.html` → 本地选择照片 → FileReader 读取 → Fabric.js 编辑 → IndexedDB 自动保存 → 浏览器导出 PNG/JPG/WebP。

照片和画布数据不发送到本站服务器。反馈页通过用户本机邮件客户端生成邮件，不在网站端收集或储存表单。

## 异常与降级

- JavaScript 动画失败时内容仍保持可见。
- 邮件客户端未配置时，反馈页提供复制邮箱。
- 浏览器不支持 IndexedDB 时，编辑功能仍可用，但不承诺自动恢复。
- 外部字体加载失败时回退到本机中文衬线与系统字体。

## 验收

- `npm run build` 生产构建通过。
- 编辑器脚本通过 `node --check`。
- 首页、案例、反馈、隐私页面在桌面与手机宽度无横向溢出。
- 六个案例裁切位置正确。
- 所有“开始创作”入口可达 `/editor/index.html`。
- 图片上传、自动拼贴、刷新恢复、PNG/JPG/WebP 导出完成一次真实流程。
